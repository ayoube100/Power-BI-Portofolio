# Power BI Procurement Analytics Dashboard

## Project Overview

Dieses Projekt zeigt die Entwicklung eines interaktiven **Power-BI-Dashboards zur Analyse der Einkaufs- und Lieferantenperformance** eines internationalen Produktionsunternehmens mit sieben europäischen Werken.

Die zugrunde liegenden Einkaufsdaten stammen aus einem SAP-ähnlichen Datenmodell und enthalten bewusst verschiedene Datenqualitätsprobleme. Ziel des Projekts ist es, die Daten zunächst aufzubereiten und anschließend zentrale Einkaufskennzahlen in einem Management-Dashboard transparent darzustellen.

## Business Questions

Das Dashboard unterstützt unter anderem die Analyse folgender Fragestellungen:

- Wie hoch ist das gesamte Einkaufsvolumen?
- Welche Lieferanten haben das größte Einkaufsvolumen?
- Welche Warengruppen entwickeln sich positiv bzw. negativ?
- Welche Lieferanten weisen verspätete Lieferungen auf?
- Welche Werke haben das höchste Einkaufsvolumen?
- Wo bestehen potenzielle Einsparmöglichkeiten?
- Welche Lieferanten gehören zu den Top 10 nach Einkaufsvolumen?
- Welche Lieferanten gehören zu den Top 10 nach Einsparungen?
- Wie unterscheiden sich Einkaufsvolumen, Einsparungen und Liefertermintreue zwischen den Werken?
- Wie verteilt sich das Einkaufsvolumen auf unterschiedliche Währungen?
- Wie können unterschiedliche Währungen für die Analyse einheitlich in EUR umgerechnet werden?

## Key KPIs

Für die Analyse wurden mehrere Einkaufs-KPIs entwickelt, darunter:

- Einkaufsvolumen
- Einsparungen
- Einsparquote
- Liefertermintreue
- Anzahl Bestellungen
- Anzahl Lieferanten
- Durchschnittliches Bestellvolumen
- Verspätete Lieferungen
- Einkaufsvolumen nach Werk
- Einkaufsvolumen nach Warengruppe

## Dashboard Features

Das Dashboard beinhaltet:

- Interaktive Filter und Slicer
- KPI-Karten für zentrale Einkaufskennzahlen
- Ampellogik zur schnellen Bewertung der Performance
- Drill-down von **Werk → Lieferant → Bestellung**
- Top-10-Lieferanten-Analysen
- Analyse von Einsparpotenzialen
- Analyse verspäteter Lieferungen
- Vergleich der sieben Werke
- Analyse verschiedener Währungen
- Umrechnung der Einkaufswerte in EUR
